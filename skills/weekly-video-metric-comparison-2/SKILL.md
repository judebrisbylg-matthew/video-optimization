# Weekly Video Metric Comparison 2

## Purpose

补齐或修订用户指定的周度视频分析区。用指标定位漏斗问题，用运营原因和逐行截图支持视觉判断，再给出可直接制作的执行结论。

**REQUIRED PRECEDING SKILL:** 七项指标对比或绿色标记缺失时，先使用 `weekly-video-metric-comparison`。

**REQUIRED SUB-SKILL:** 使用 `spreadsheets:Spreadsheets` 检查、编辑和验证工作簿。

编辑前阅读 [references/analysis-rules.md](references/analysis-rules.md)，获取运营原因、图片匹配、场景和色彩判断规则。

## Workflow

1. 以用户最新手改文件为基准，仅处理第一张表中本次指定的周次、筛选范围及实际业务行；按广告、ASIN、SKC、Spend 等锚点识别行，不把历史数据或空白格式行纳入本周任务。
2. 先查看相关区域，按**多行表头和用户意图**建立字段映射。列字母及“图2”不是固定字段定义。定位数据结论/原因、视觉结论/原因、运营原因、当前截图、右侧好素材及其链接；存在冲突时先澄清目标字段，不修改表头。
3. 选择所需模式；请求同时包含两块时分别处理：
   - **数据诊断：**依据七项指标对比写漏斗原因和下一步验证方向；无截图不阻塞数据诊断，但不能据此编造视觉缺陷。
   - **视觉分析：**先读本行运营原因及相关备注，再将当前截图与右侧好素材逐行匹配比较，结合指标写原因与执行结论。运营提出的色差、泛白、产品结构等问题必须核对并回应。
4. **默认只填空白。**用户明确要求修订时，可以改写指定范围内已有目标文案；用户手改或明确保留的条目继续保护。所有非目标单元格、表头、公式、图片、样式、筛选状态及其他工作表保持不变。
5. 保存源文件旁的新版本；沿用用户当前文件命名和版本序列。无既定规则时使用 `<original>_视频指标及视觉分析.xlsx`，去掉重复的 `_补齐视频指标对比` 后缀。不要覆盖源文件。
6. 重开文件，比较源文件与输出的修改单元格清单，核对仅授权字段变化、保留条目逐字一致、图片和公式完整、无新增公式错误。通过 WPS 或可用渲染查看文字是否截断、换行及图片显示；未能完成可视检查时明确说明。

## Evidence Gates

- 当前截图缺失或无法确认行归属时，不新写截图支持的视觉诊断；保留已有内容，列出待核对行。参考截图缺失时只分析当前图，不声称做过参考对比。
- 两张静态图不能证明节奏、转场、声音、运动过程或视频其余部分；指标与画面差异也不能证明因果关系。
- “数据好的素材”是参考身份，不等于场景、颜色导致成功；没有参考指标时不编造数值或提升幅度。
- 已有人工结论与证据冲突时，默认保留并报告；若本次明确授权修订该条，则按核实的证据修订。明确要求保留的条目仍不覆盖。

## Output Contract

### 数据诊断

- `数据分析原因`：关键强弱指标 + 漏斗含义，通常 45–100 字；优先写最能解释问题的指标，不罗列全部数据。
- `数据分析结论`：应保留的方向 + 有依据的下一步验证动作；区分视觉问题和价格、关键词、竞价等运营因素。
- CPC、ACOS 通常越低越好，CTR、CVR、5秒观看率、完播率通常越高越好；Spend 是规模信息，不直接判优劣。以表内已确认口径为准。

### 视觉分析

- `视觉分析原因`：关键漏斗表现 + 已核对的运营问题 + 当前图与参考图的主要可见差异，通常 60–110 字，按证据和单元格可读性调整。
- `视觉分析结论/执行结论`：场景或前提 + **第一分镜**的景别、动作与商品展示点 + **第二分镜**的不同展示信息 + 必要的色彩或结构约束，通常 40–80 字，可按内容调整。
- 此周报的前5秒优化默认写两个分镜，使用“第一分镜／第二分镜”，不默认固定秒数。用户明确要求时间分配或全片方案时再按要求扩展，不自动附加10–15秒版本测试。
- 写具体场景、动作和商品证据，避免“提升质感”“增强钩子”等空泛结论。不要给每款机械套用同一种场景或面料近景。

## Completion Report

交付最终工作簿，说明工作表、填充/修订及待核对行数、图片归属疑点与新增公式错误情况。除非用户要求，不交付中间版本。
