# Analysis Rules

## 字段与指标口径

按当前多行表头识别字段，不硬编码 DD/DE。在一种现有布局中，CU:DA 是七项对比，DB/DC 是数据结论/原因，DD/DE 是视觉结论/原因，CC 是运营原因，DF/DG 是当前截图，DJ/DK、DL/DM 是两组好素材，CP/CQ 是参考链接。**这些只是定位示例，每次重新核对。**

常见口径是 CPC/CVR/ACOS 对父体全渠道，CTR/5秒观看率/完播率对父体视频；当前工作簿的明确表头或已确认口径优先，不能擅自统一基准。

## Metric funnel map

使用 `weekly-video-metric-comparison` 已确认的对比结果。以下只是查证起点，不能代替逐行证据。

| 指标组合 | 诊断起点 | 要核对的画面或运营证据 |
|---|---|---|
| CPC/CTR 弱，CVR/ACOS 健康 | 引流效率弱，已点击人群能够购买 | 商品占比、场景匹配、对比度；同时查看竞价/关键词 |
| CTR 健康，5秒观看/完播弱 | 点击后观看留存弱 | 两帧是否重复、第二帧是否增加商品信息 |
| 点击及观看健康，CVR/ACOS 弱 | 购买环节待排查 | 材质/版型/细节证据，以及价格、关键词、产品版本 |
| CVR 健康，观看弱 | 保留有效商品表达，改善开头 | 主体清晰度与不同分镜的信息增量 |
| 六项效率指标均弱 | 优先核对定位与开头 | 商品是否过远、背景是否抢主体、运营条件是否变化 |
| 只有 CPC 弱 | 无法单独归因视觉 | 竞价、受众等因素；有可见缺陷才给视觉动作 |

CPC 低于基准不能与低 CTR 一起写成“均表现差”。没有截图时，数据诊断可以提出待验证方向，不能断言节奏慢或具体画面存在缺陷。

## 逐行证据顺序

1. **运营原因：**先读本行运营原因、相关标记和备注，包括色差、泛白、其他品牌文字、产品结构调整、价格、关键词、生命周期。记录需要核实的问题，区分备注报告与已观察事实。
2. **当前截图：**查看前5秒的两张图，识别商品占比、裁切、场景与款式关系、服装/背景反差、曝光和细节。只有表头明确标注时才把截图1称为首帧。
3. **右侧好素材：**按行对比相应两组参考；说明借鉴哪组的什么特点。区分同款同色、同款异色与仅场景参考，不能跨颜色拿参考图当色准。
4. **指标交叉判断：**选出最关键的制作问题，解释其可能影响的漏斗环节。运营问题、参考差异与指标不一致时保留不确定性，不为了补满格子强行归因。

原因要充分，执行要简洁。不要把所有运营问题都塞进分镜，但色准、产品版本等制作前提要进入结论；关键词和价格问题归入数据/运营建议。

## Row and image matching

- 浮动图片使用 drawing 顶部左侧锚点行和已解析的截图表头组共同定位；跨行或归属不明时标记待核对。
- WPS `DISPIMG` 图片用对应单元格公式中的图片 ID，经 `cellimages.xml` 及其关系文件定位媒体；同时保留单元格行号和表头组。
- 不按文件名、包内顺序、全局图片顺序或视觉相似度配行。确认行与组之后，才按组内顺序比较。
- 父体代表商品缩略图不一定是本行 SKC 的颜色标准；保持图片、公式、关系文件完整，优先采用不会丢失 WPS 图片的定点编辑方式。

## 色彩与产品结构

- **色准**、**曝光泛白**、**饱和度**和**服装/背景明暗反差**分别判断。核对色差需同 SKC 已确认实物或商品图；缺少标准时把“核对实物色”写为制作前提，不直接宣布已判定偏色。
- 白裙可要求控制高光、保留褶皱层次；不能改成米黄或灰色来解决泛白。异色好素材只借鉴场景和展示方式。
- “中灰/浅灰”指真实灰色，不等于低饱和，也不等于适中明度。若目的是让商品突出，直接写“明暗适中、与服装有反差、光线均匀”。低饱和背景仍可能太亮。
- 运营提出“改成前面绑带”等结构调整时，先核对已确认的新款/实物版本；按确认版本制作，不凭文字备注新增结构，也不以旧图否决已确认的产品更新。
- 可见其他品牌文字应列入去除/替换动作；保持本款真实颜色、版型和细节，不照搬参考服装或搭配。

## 季节与场景

- 以预计推广时间判断季节，而不只看文件编辑日；本工作流9月制作需考虑后续秋冬推广。
- 秋冬不等于全部室内。逐款结合款式、穿着用途和有效参考，选择适合的城市街道、石质庭院、柱廊、咖啡店外景或室内空间。
- 在秋冬推广要求下，优先替换热带海滩、泳池、强热带绿植等明显盛夏场景；兼容季节的有效参考场景可以保留。
- 不为秋冬强制灰背景、改衣服颜色或添外套。写明具体场景及其商品展示用途，不能只写“换高级场景”。

## Writing example

示例前提：白色披肩裙 CTR 与5秒观看弱、CVR/ACOS健康；运营指出泛白；当前两图商品偏远且海边场景明显盛夏；右侧第二组是柱廊全身和披肩近景。仅在这些证据实际存在时使用下列思路：

```text
视觉分析原因：转化与ACOS健康，但点击和5秒观看偏弱；运营提到泛白，当前远景不利于看清白裙褶皱。右侧第二组柱廊图的主体更突出、披肩信息更清楚，可借鉴其展示方式，并调整海边场景以适应秋冬推广。
执行结论：参考右侧第二组柱廊场景：第一分镜，全身走近展示裙型；第二分镜，近拍抬臂展开披肩与裙身褶皱。核对实物白色，控制高光。
```

执行结论是拟制作的动作；原因只描述已看到的姿态/画面，不把静态截图解释成完整运动过程。避免未经依据描述模特吸引力、种族或年龄，不把模特身体特征当作效果原因。

## 交付前内容检查

- 是否按本次周次和实际表头定位，保留用户手改及所有非目标内容？
- 是否逐行读过运营原因，并回应已发现的色差、泛白、品牌文字或结构问题？
- 当前图与好素材是否正确配行，是否区分异色参考和同 SKC 色准？
- 原因是否证据充分，执行是否包含两个有区别的分镜且没有默认秒数模板？
- 场景是否适合实际推广季节和款式，而不是全表统一室内或灰背景？
