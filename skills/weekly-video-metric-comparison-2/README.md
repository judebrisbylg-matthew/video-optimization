# 视频视觉分析与执行结论

`weekly-video-metric-comparison-2` 用于周度表格的数据诊断、图片核对和执行结论填写。

[返回视频优化总入口](../../README.md) · [查看完整规则](SKILL.md) · [在线制作流程](https://judebrisbylg-matthew.github.io/video-optimization/)

## 用途

按授权范围填写或修订四类字段：数据分析原因、数据分析结论、视觉分析原因、视觉执行结论。指标或绿色标记缺失时，先运行 [指标对比 Skill](../weekly-video-metric-comparison/)。

## 需要提供什么

- 最新 XLSX、目标日期及授权修改的字段。
- 对应业务行的当前视频前5秒截图。
- 对应优秀素材截图（如有）、运营备注。
- 涉及色差或结构时，提供同SKC确认商品图或实物标准。

## 使用步骤

1. 锁定第一张工作表和指定周次，按实际表头识别字段。
2. 读取运营备注，匹配本行当前截图及参考截图。
3. 对照指标定位问题，区分已观察事实和待验证原因。
4. 原因讲充分，执行写简约；不需要优化时保留素材。
5. 检查非目标内容、图片与公式未被改变，保存新版本。

## 推荐写法

场景只说明大方向和色调，具体找景交给设计师。

```text
（1）测试有生活气息的纽约街头咖啡店场景，以灰米色、木色为主。
（2）第一分镜展示完整裙型；第二分镜展示腰臀花纹与垂感。
```

不需要优化时：

```text
（1）CPC、点击率、5秒观看率和完播率表现良好，建议暂不优化，保留现有素材。
```

以上仅为写法示例。条数按实际需要，不固定三条；不要所有款式都换成相同场景。只校色或保留素材时，不强行添加分镜。色差、印花及结构问题需独立核实。

## 安装

在 Codex 中发送：

```text
请使用 $skill-installer 安装：
https://github.com/judebrisbylg-matthew/video-optimization/tree/main/skills/weekly-video-metric-comparison-2
```

手动安装时，将本目录完整复制到 `~/.agents/skills/` 或项目 `.agents/skills/`，保留 `references/` 和 `agents/`。已有同名目录先备份。需要宿主提供 `spreadsheets:Spreadsheets`，详见[安装总说明](../../README.md#安装方法)。

## 使用示例

```text
使用 $weekly-video-metric-comparison-2，仅分析第一张表中【日期】的行。
原因写充分，执行简约并按需分点。换景只写大概场景与色调，不写具体布景清单。
不需要优化的只写一条，不强行补两个分镜。保留其他日期、已有人工保留项、图片和公式，另存新版本。
```

本体保留现有版本；上述简约偏好请在使用时明确附带。无当前截图不编造视觉原因；只有静态截图时不推断全片节奏。HTML 说明中的建议同步项尚未写回本体。
