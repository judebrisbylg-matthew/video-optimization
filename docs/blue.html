03 / 先判断要不要改，再决定怎么改

切换典型情况，查看处理分支
指标定位 → 图片核实 → 有限度的动作

优先保留，不强制优化

确认没有商品错误或必须修正的问题后，建议暂不优化。转化和ACOS若仍偏弱，单独排查流量与商品页承接。

（1）CPC、点击率、5秒观看率和完播率表现良好，建议暂不优化，保留现有素材。

标绿表示相对已确认基准较好，不代表所有问题都已排除；静态截图与指标不能证明因果。

04 / 四个字段，各写各的

以下为写法示例，不对应本周某一行的实际结论
数据分析原因

关键指标＋问题环节

通常45–100字，说明判断依据。
转化率和ACOS较好，但点击率及两项观看低于基准。已点击人群有购买表现，需优先核查引流与观看环节，不直接认定为场景问题。
数据分析结论

保留什么＋验证什么

按实际情况分点，不硬凑三条。
（1）保留有效商品表达，测试更清晰的开场。 （2）结合搜索词与点击人群，观察观看和转化变化。
视觉分析原因

指标表现＋可见画面证据

通常60–110字，分清已观察事实与待验证推断。
当前两图景别接近，第二图主要增加扶眼镜姿态，商品细节增加有限。参考第一组由完整裙型切至腰臀，展示信息更明确，可借鉴景别变化，不能据此断定背景导致低效。
视觉分析结论 / 执行动作

场景＋色调＋展示重点

通常40–80字；只写必要动作。
（1）测试有生活气息的纽约街头咖啡店场景，以灰米色、木色为主。 （2）第一分镜展示完整裙型；第二分镜展示腰臀花纹与垂感。

纽约街头仅为示例，不是统一模板。按款式、推广季节及已有效的素材选择场景。

05 / 交付前的三道检查

范围没有扩大

只改指定周次和授权字段。默认填空；明确要求修订时再改已有文案。保护人工保留项。

判断有证据

图片与行对应；色准用同SKC标准；缺图不编造，不把两张截图解释成全片节奏。

表格没有损坏

重开验证文字、公式与图片，比较非目标内容。新版本保存，不覆盖原文件。

分点数量灵活，不优化只写一条

明确写入：用（1）（2）按需分点，不固定三条。不需要优化时列出表现良好的指标，并写“建议暂不优化，保留现有素材”。商品真实性问题仍单独修正。

两分镜只用于确实需要调整的素材

现有 skill 默认要求两个分镜，应补充例外：保留素材、仅校色或待核实问题时，不强行新增分镜。需要改分镜时说明两个不同的商品展示点。

固定“半年”的基准表述，需要增加口径冲突检查

指标 skill 仍描述半年基准，而实际周表可能包含近30天或近90天字段。建议写入：先核对表头与数据期间，发现冲突先确认，不把不同期间默认当作同一基准。
